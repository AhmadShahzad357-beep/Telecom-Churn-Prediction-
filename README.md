# Telecom Customer Churn Prediction

Rebuild in progress.

**Problem:** Using June-August behaviour, predict which high-value prepaid customers
will become completely inactive in September, and how much revenue is at risk.

**Churn definition:** in month 9 the customer made no recharge (calls or data)
AND had zero incoming calls, outgoing calls and mobile data usage.

**High-value customer:** top 30% by average June-July spend (call + data recharge).
